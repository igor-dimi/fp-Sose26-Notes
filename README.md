# Mixed-Precision Iterative Refinement

This repository contains a C++ implementation and experimental framework for three-precision LU-based iterative refinement for solving linear systems.

The project uses:

- **HDNUM** for numerical linear algebra,
- **CPFloat** for simulated low-precision arithmetic,
- **GMP** for high-precision arithmetic,
- **Python** for plotting experimental results.

The repository also contains the experiment drivers, plotting scripts, generated results, project report, and a more detailed project guide.

The most relevant directories are:

- `code/include/`: mixed iterative refinement implementation and helper headers.
- `code/experiments/`: experimental drivers.
- `code/scripts/`: plotting scripts and shared Python utilities.
- `code/tests/`: correctness and sanity tests.
- `code/external/`: external dependencies, including the HDNUM submodule.
- `results/raw/`: generated CSV files.
- `results/plots/`: generated figures.
- `report/`: final project report.
- `manual/`: detailed project guide.

## Setup and Dependencies

### Prerequisites

The project requires:

- a C++17-compatible compiler,
- CMake 3.20 or newer,
- Ninja,
- Git,
- GNU Make,
- GMP with C++ support,
- Python 3 with NumPy, pandas, and Matplotlib.

### Clone the Repository

Clone the repository together with its submodules:

```bash
git clone --recurse-submodules <repository-url>
cd <repository>
```

If the repository was cloned without submodules:

```bash
git submodule update --init --recursive
```

HDNUM is provided as a Git submodule under:

```text
code/external/hdnum/
```

### CPFloat

CPFloat must be cloned inside the HDNUM directory and built separately:

```bash
cd code/external/hdnum
git clone https://github.com/north-numerical-computing/cpfloat.git
cd cpfloat
make lib
cd ../../../..
```

The build is expected to produce:

```text
code/external/hdnum/cpfloat/build/include/
code/external/hdnum/cpfloat/build/lib/libcpfloat.a
```

### GMP

On Debian/Ubuntu systems:

```bash
sudo apt install libgmp-dev
```

### Python Packages

Install the plotting dependencies with:

```bash
python3 -m pip install numpy pandas matplotlib
```

Optionally, use a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install numpy pandas matplotlib
```

## Building the Project

The repository-level `Makefile` provides the simplest interface.

Build the release configuration:

```bash
make build
```

Build the debug configuration:

```bash
make PRESET=debug build
```

Run the test suite:

```bash
make tests
```

or in debug mode:

```bash
make PRESET=debug tests
```

The underlying CMake presets can also be used directly from `code/`.

## Running the Experiments

Run all experiment drivers with:

```bash
make experiments
```

Individual experiments can be run with:

```bash
make experiment-convergence-histories
make experiment-condition-sweeps
make experiment-residual-precision
make experiment-direct-solve-comparison
make experiment-residual-scaling
```

The generated CSV files are written to the corresponding subdirectories under:

```text
results/raw/
```

## Plotting the Results

Generate all plots with:

```bash
make plots
```

Individual plotting tasks are available through:

```bash
make plot-convergence-histories
make plot-condition-sweeps
make plot-residual-precision
make plot-direct-solve-comparison
make plot-residual-scaling-diagnostics
make plot-residual-scaling-errors
```

To regenerate both the experimental data and all figures:

```bash
make reproduce
```

Generated figures are written under:

```text
results/plots/
```

## Results Directory

Experimental output is separated from the implementation:

```text
results/
├── raw/      # CSV files produced by the C++ experiment drivers
└── plots/    # figures generated by the Python plotting scripts
```

The required result directories are created automatically as needed.
